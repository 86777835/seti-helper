## 先说四个事实

- **中文版**：简中名《星空觅迹：探寻地外文明计划》，香港**栢龍玩具**出版，2025 年 9 月底上架即售罄。扩展 Space Agencies 简中名《星空觅迹：**群星计画**》（“计画”不是“计划”），2026 年出版。
- **术语**：CGE 官网有**官方简中规则书 PDF**，已用它核对。站内一律用官方词：推广（不是宣传）、绕行 / 人造卫星（不是环绕）、着陆 / 着陆器（不是登陆）、生命迹象、免费行动、太阳系公转、跳过本轮、金色计分板块、金色里程碑、冗余位置、一轮结束牌、条件任务 / 触发任务。五种外星生物：硫铵虫、异常点、奥陌陌、半人马族、钻探者。国内先流通过好几种盗版，各有各的译名（宣传、声望、登陆、痕迹、虫族……），所以术语注释里会列出常见别名，方便对照桌上的实物。
- **没有现成的中文线下工具**。现有工具都是英文：官方的太阳系随机网页、英文开局向导、单人对手助手（brdgm.me）、粉丝查卡站。BGA 和 Steam 都没有 SETI。
- **最大痛点是规则，不是记账**。BGG 规则区：外星生物占 25%，扫描和扇区占 15%，时机和结算顺序吵得最凶。B 站：首局 4–6 小时、“没听懂”。终局计分只有三项（金框卡、金色计分板块、部分外星生物），远比方舟、勃艮第简单。

## 做

| # | 功能 | 内容 | 依据 |
|---|---|---|---|
| 1 | **开局配置 + 布置清单** | 人数 1–4，可勾选扩展《群星计画》。起始玩家跳转总入口去定，然后按座位提示起始分 1 / 2 / 3 / 4，以及起始资源（推广 4、信用点 4、能量 3、5 张牌，再插 1 张收入牌并立刻拿资源）。按人数生成勾选式清单，每条标规则书页码：中立里程碑（1–2 人各 2 个、3 人各 1 个、4 人不放）、一轮结束牌 4 叠每叠人数 + 1 张、科技每种都放 4 块（**不按人数减少**）且奖励面朝上、外星生物 2 块背面朝上、数据放满每颗恒星。太阳系布局直接链到官方随机网页。开局时记下 4 块金色计分板块各是哪一面，终局计分会用到 | B 站“set 太麻烦”；BGG 有 2 人局把科技少放的“勘误”争吵（44 帖）、“2 人局没有特殊规则？”（24 帖）、科技朝向印错（CGE 承认） |
| 2 | **轮次流程（5 轮）** | 每人手机上一个“我跳过本轮”按钮，按下就弹出跳过的三步：弃到 4 张手牌 →（本轮第一个跳过的人）转太阳系，附怎么转的图 → 选一张一轮结束牌。全员跳过后显示轮间维持：拿收入、起始玩家左移、公转标记移到下一叠。**第 5 轮不拿收入，但第一个跳过的人仍要转**。如果已发现异常点，转完提醒检查地球是否和异常点同扇区。另有一张折叠的“别忘了”卡：研究科技要先转再拿、移动力不能留到后面用、扇区在主行动结束时结算、里程碑在回合结束时结算、免费行动只在自己回合做 | BGG 误解 Top 20 里有 6 条是流程和时机问题；“第 5 轮还拿收入”“第 5 轮不转”是高频错 |
| 3 | **外星生物揭晓** | 某个种族被发现时，任一人点“发现了 ×××”，所有人手机上弹出该种族的说明：揭晓时怎么摆、新规则要点、最常见的 3–5 个误解，用自己的话写，标外星生物说明的页码。包含扩展的 3 个新种族。规则书本来就建议揭晓时再学，不用开局全讲 | 外星生物占 BGG 规则区 25%（136 个主题）；B 站“说漏了揭晓时机”；钻探者、半人马族、奥陌陌各有一串反复被问的问题 |
| 4 | **终局计分（每人用自己手机填）** | 分项：分数条上的分数（含 100 / 200 分标记）、金框计分牌、金色计分板块（只列开局记下的那一面，选自己标在第几格，填达成几套，自动相乘，条件旁写清防错提示）。有钻探者时：每人填危险值和钻探者牌得分，自动扣**危险值最高者总分的十分之一**（危险值为 0 的不扣）。另有全桌总览，没手机的人由别人代填。平局按规则共享胜利。单人局多一栏对手得分，含“每个未完成目标对手 +5 分” | BGG 误解第 1 条是“放金色标记时就得分”；收入板块误算起始收入牌；钻探者扣分有 CGE 正式裁定（36 帖）；中文社区没有任何计分工具 |
| 5 | **结算 + 往期对局** | 排名、得分构成、存长图、评价卡（跳总入口），往期对局存档 | 系列统一 |
| 6 | **讲规则页（约 6 分钟）+ 注意事项 + 规则助手** | 讲稿按探测器线（发射 → 移动 → 绕行 / 着陆）和望远镜线（扫描 → 信号 → 扇区 → 数据 → 计算机 → 分析）两条主线讲，再讲打出卡牌、研究科技、生命迹象、里程碑、终局；外星生物等揭晓时再讲。注意事项约 20 条，取自 BGG 误解 Top 20 和官方 FAQ（含 CGE 2025-12 才正式裁定的“移动力不能存”，很多老视频讲错了）。图片截自 CGE 官方简中规则书和快速参考，页脚署名。规则助手接联网查找 | B 站讲规视频纯规则部分 20–30 分钟，10 分钟版被评论区纠错；BGG 教学讲稿和精简 FAQ 有人要 |

## 要你决定的三件事

**A. 扩展《群星计画》一起做吗？** 建议**一起做**。
- 它改了开局（研究机构代替起始收入牌、快速起始牌、推广从 0 开始），只打 4 轮，收入在第 3、4、5 轮开始时拿。这些正是容易乱的流程。另外它多了 3 个新种族，揭晓时要看说明。
- 扩展是 BGG Golden Geek 年度最佳扩展，简中版已出。
- 工作量：布置清单、轮次、种族说明、计分各加一套分支，讲规则页加“带扩展”开关（照奥丁）。11 个研究机构每个写一句话说明。

**B. 单人模式做到哪一步？** 建议**只做开局清单和计分**（含对手得分）。
- 对手的行动牌堆和进度轨，英文的 brdgm.me 已经做得很完整（BGG 95 赞）。重做等于做半个数字版，也不符合“线下用实物更方便的留在线下”。

**C. GitHub 仓库**：现在建 `86777835/seti-helper`（分支 `main`），把调研文档和这份清单推上去，之后每次改动都同步，可以吗？部署和域名（`seti.leisurecat.cloud`，Worker `seti-helper`）等开发完再问你。

## 不做（留在线下）

| 环节 | 理由 |
|---|---|
| 信用点、能量、推广、数据、手牌、收入计数 | 实物一目了然；两边同时记账反而容易对不上，也等于做半个数字版 |
| 分数条实时记分、里程碑触发 | 分数条和里程碑都在版图上；终局时填一次分数条上的总分就够 |
| 太阳系公转计数（下次转第几层） | 科技版图上有实物公转计数标记；只在“第一个跳过”时提醒去转，并配图说明怎么转 |
| 太阳系随机布局 | 官方随机网页已有，清单里直接放链接 |
| 抽外星生物、金色计分板块的随机朝向 | 实物洗混更快，外星生物还必须保持背面朝上 |
| 扇区、信号、探测器位置 | 版图上看得最清楚 |
| 单人对手自动机 | brdgm.me 已做（见 B） |
| 完整卡牌词典 | 基础 138 张主牌加外星生物牌，中文已有粉丝查卡站。易混的卡写进常见问题，规则助手也能答 |
| 2 人局扫描村规（预放中立标记等） | 不是官方规则。扩展里官方给的 1–2 人可选开局，写进扩展的布置清单 |
| 在线对战 | 超出范围 |
